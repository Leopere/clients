# Vaultwarden Companion Browser Fork

This repository is the public `Leopere/clients` fork of
[Bitwarden Client Applications](https://github.com/bitwarden/clients). Only the
**Vaultwarden Companion** Firefox extension is maintained here. Other inherited
GPL application source remains upstream-derived and outside this fork's release scope.

See the fork-specific process in [`apps/browser/FORK.md`](apps/browser/FORK.md).

Fork lineage:

- Upstream remote: `bitwarden/clients`
- Local fork remote: `Leopere/clients`

## Scope and compatibility

This fork keeps upstream browser code and behavior compatible where possible. It is not a
Bitwarden-affiliated product.

## Attribution and licensing

The repository includes upstream OSS source, compatible upstream attribution, and required license notices:

- `LICENSE.txt`
- `LICENSE_GPL.txt`
- `LICENSE_BITWARDEN.txt`
- third-party notices in the repository

The fork adds its own name, iconography, and distribution metadata under ColinKnapp.com ownership.

## Contributing

Code contributions are welcome. Start with [`apps/browser/FORK.md`](apps/browser/FORK.md), follow the browser-specific identity and release checks, and keep build changes scoped to fork-owned browser inputs.

Security reports and sensitive feedback remain welcome. See [`SECURITY.md`](SECURITY.md).
