# Vaultwarden Companion icon

The icon is original artwork for Vaultwarden Companion. It uses a vault-door and keyhole motif
that is visually distinct from Bitwarden and Vaultwarden artwork. The normal, disabled, and locked
toolbar files preserve separate status treatments at 19 px and 38 px.

The master was generated with OpenAI's built-in image-generation tool, then corrected locally to
remove generation artifacts and produce transparent, size-specific PNG files. The final prompt
requested a centered circular vault door, teal outer ring, navy center, warm-white keyhole, amber
status dot, flat geometric shapes, no text, no shield, no castle, and no trademarked artwork.
